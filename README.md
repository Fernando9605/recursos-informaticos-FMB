# recursos-informaticos-FMB

## Descripción
Este proyecto es una página web educativa que reúne recursos
útiles para aprender informática y desarrollo web.

## Contenido
- `index.html`: estructura y contenido de la página.
- `style.css`: estilos visuales de la página.
- `README.md`: documentación del proyecto.

## Recursos incluidos
- [GitHub](https://github.com/): plataforma para gestionar proyectos.
- [MDN Web Docs](https://developer.mozilla.org/es/): documentación web.
- [W3Schools](https://www.w3schools.com/): tutoriales de programación.

## Tecnologías utilizadas
- HTML5
- CSS3
- GitHub para alojar el proyecto y registrar los cambios.

## Autor
Proyecto realizado como actividad educativa.
